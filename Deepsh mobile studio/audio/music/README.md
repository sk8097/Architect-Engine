## Monetization and publishing gate

**No track in this inventory is approved for monetized publishing by this repository alone.** Before use, record:

1. Original creator and source URL.
2. Licence name and a copy/snapshot of the licence terms.
3. Whether commercial use, modification, attribution-free use, and YouTube monetization are allowed.
4. Required attribution text, if any.
5. Proof that the licence covers the actual channel/account and the date of publication.

Do not infer permission from filenames, “no copyright” labels, folder names, or a subscription badge. Tracks with missing proof must remain unused in monetized exports.
