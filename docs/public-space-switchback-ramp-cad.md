# Public-space switchback ramp CAD

Choose **Infrastructure → Public realm / landscape / waste → Public Park, Public Garden, Urban Plaza or Playground → Automatic drawing → Public-space ramp: two flights and turning landings**. Use **Public Open Space** on a measured rectangular or square plot with cardinal frontage. Leave floors, parking and separate Space selections empty.

Enter lower, turn and upper landing levels on one survey datum. Both flights have the same supplied horizontal run and clear width, but each slope is computed from its own rise. The lower entry and upper exit landings are side by side at the front; two parallel flights join via one shared level landing at the rear. Enter both landing depths, separator reserve and offsets. The interior clear footprint is `2 × flight width + divider` by `endpoint landing depth + run + turn landing depth`.

Supply the minimum clear flight width and square clear turning space, maximum rise per flight and maximum slope percentage. The drawing shows the clearance squares inside all three landings; it conservatively requires one flight width to accommodate the square. The footprint must fit the measured plot and supplied setbacks. These are user-entered thresholds, not default accessibility standards.

Example: on a **20 × 25 m** plot, start **3 m** from the left and **2.5 m** from the front. Use **8 m** runs, **1.8 m** clear widths, a **0.25 m** separator, **2 m** endpoint landings and a **2.2 m** rear landing. Levels **100.000 / 100.480 / 101.040 m** produce **6%** and **7%** slopes. With minimum **1.8 m** clear width, **1.5 m** turning squares, **0.560 m** max rise and **7%** max slope, the internal footprint is **3.85 × 12.20 m**. The marked centreline gives **24.250 m** of horizontal chainage, including level landings and the rear traverse. It is not a vehicle or mobility-device swept path.

Save to preview the plan and unfolded true-scale profile; each exports as a layered editable DXF. Profile X is horizontal chainage along the marked centreline; Y is height above lower landing, both in millimetres. Reopen **Switchback ramp CAD** from Projects. A failed measured check preserves the brief and blocks both exports. The drawing does not verify terrain tie-ins, crossfall, rail/guard build-ups, drainage, structural design or accessibility compliance. Allow separately for those features in the available site area.
