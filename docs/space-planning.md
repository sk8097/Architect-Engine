# Configuration-first space planning

1. New Project uses the existing category → group → type taxonomy. Configuration starts with measured plot sides and a unit, the surveyed area for other shapes, or route length and right-of-way for corridor projects. No invented measurements. Switch units to convert, not reinterpret, existing dimensions.
2. The selected **program** supplies essential questions: e.g. bedrooms for a dwelling, workstations for an office, flow/department information for specialist uses, and commodity plus clear height for a warehouse. Configuration blocks if essential inputs are missing. Detailed nonessential questions remain later in the wizard.
3. The fixed top summary reports plot sqft, an estimated usable envelope from measured geometry and supplied setbacks, and the minimum planned area and remaining budget by floor. For a surveyed irregular plot it is an area-only screening with no known width/depth. For non-residential rooms, enter your actual area or clear dimensions rather than borrowing a generic residential template. Linear projects use measured corridor information and do not display a building sqft budget.
4. Known residential options use **editable planning allowances**, with separate minimum and typical estimates, not statutory minima. Passes area and individual width/depth screening, not complete geometric packing. Wall/passage percentages are preliminary concept allowances. Over-budget selections are kept visible so they can be corrected. Covered core elements are not counted twice when selected for more detail.
5. A dwelling reserves a kitchen and at least one bathroom. The user can choose kitchen type, bathroom counts, and no prayer space, niche, corner or separate room. Vastu can be recorded upfront with facing; suggestions are advisory and do not control the current CAD solver.
6. Multi-floor or terrace access asks about stairs, inside/outside/shared access, stair shape, lifts and how upper floors will be accessed. Upper floor budgets and access footprints are supplied by the user. Multi-floor homes assign bedroom and bathroom counts and a main kitchen/living floor. An accessible terrace combines separate open, covered, enclosed or garden zone areas. Terrace use, stair safety, rental unit requirements, allowable floors, local rules, structure and drainage are not verified by the budget.

These are intake and early budgeting features, not new CAD generators. Floor plans and DXF still require the existing supported low-rise single-floor brief; an unsupported request is not silently dropped to make a drawing.
