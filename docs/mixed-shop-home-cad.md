# Side-by-side shop and dwelling CAD

**New Project → Mixed Use → Mixed-use development → Residential + Retail → Automatic drawing → Shop + dwelling: side-by-side with independent entries**. Use a new ground-floor rectangular or square building. Select Horizontal Mixed Use if choosing an arrangement. The shop is on the left when looking in from the shop frontage. Provide the building dimensions, offsets, wall thickness, shop width, total solid divider thickness, and shop and dwelling door/walk inputs. The divider is made from the two wing walls plus any remaining solid thickness; the input must be at least twice the supplied wall thickness. The dwelling uses the remaining measured width. Choose separate entry walks on the same side, or put the dwelling entrance at the opposite boundary. Confirm there is access beyond both plot boundary entries; the drawing stops at the plot boundary.

Provide shop display, checkout, aisle and stock measurements in the concept step. In Spaces, select only the actual dwelling rooms, including one living room, one closed kitchen, shared bathroom(s), and the requested number of bedrooms. The home windows must face the true outside, not the divider. Check any room-specific left/right/front/rear requirements from the perspective of the **dwelling entrance**, including when it faces the opposite side. There is no indoor shop-to-home connection. The scope includes one shop and one dwelling, not restaurants, stacked units, separate loading, parking or shared cores.

Save builds both wings as one drawing or shows a specific blocking reason; it never exports one wing in place of the mixed-use layout. Reopen from **Projects → Shop and dwelling CAD**. Editable DXF includes `MIXED_SHOP_ACCESS`, `MIXED_HOME_ACCESS`, `MIXED_DIVIDER` and the shop fixture layers. The solid divider, paths and floor plan are a concept, not a fire-rated assembly, acoustic design, engineered access, egress plan, or proof of zoning and mixed-use permission.
