# Library shelving and quiet reading CAD

Use **Institutional & Public Utility → Education → Library** or **Culture / worship / community → Public Library** and select **Automatic drawing → Library: checkout, open stacks and quiet reading**. The template uses a single new ground-floor building on a measured rectangular or square plot, with a cardinal public entrance. It does not design multiple halls or blocks, parking, an accessible roof, or a surveyed retrofit.

Choose one Library checkout/return, Open book stacks, and Quiet reading room. Children’s reading, staff book processing and a public toilet reserve are optional single rooms. Enter all clear room dimensions and any required edges or measurements for exterior windows. Checkout must touch the front edge. Checkout, stacks and optional support-room doors open before the quiet threshold; the quiet reading room opens after it. Book processing remains staff-only by intended use; no lock or hardware is specified. The optional rooms and checkout are geometry only, without furniture or plumbing details.

Enter the number of shelf ranges per bank, their footprint and the clear aisle width. The stack door meets a full-width cross-aisle, with the same measured bank of shelves and connected clear aisles on each side along the room depth. Enter the reading desk count, sizes, chair clearance and aisle width. The reading room has one row of individual desks served by a clear aisle along its door side. A request that does not fit is not shrunk or partially exported.

Save previews the generated drawing; reopen **Library reading CAD** from the project menu. Editable DXF includes the walls, openings and distinct `LIBRARY_PUBLIC`, `LIBRARY_QUIET`, `LIBRARY_QUIET_THRESHOLD`, `LIBRARY_SHELVES`, `LIBRARY_STACK_AISLES`, `LIBRARY_DESKS`, `LIBRARY_CHAIR_CLEAR` and `LIBRARY_STUDY_AISLE` layers. Non-fitting briefs remain saved and don't fall back to generic zoning.

The quiet doorway is a geometric partition, not an acoustical rating. Shelf anchorage and loads, library capacity, ergonomics, accessible facilities, emergency egress and local requirements need separate review.
