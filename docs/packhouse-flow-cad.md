# Dry fruit and vegetable packhouse CAD

**New Project → Rural / Agricultural → Agricultural processing / storage → Fruit/Vegetable Packhouse → Automatic drawing → Packhouse: receiving, grading, packing and dispatch**. The template uses one new ground-floor rectangular shell and a straight material sequence: front **receiving → grading → packaging → optional ambient finished store → rear dispatch**. Select Processing + Storage if choosing a configuration label. Confirm existing on-site access to both sides and dry ambient handling only. This does not design circulation beyond the two measured pads.

Enter the measured building envelope, offsets, wall thickness, material openings, goods lane width and dimensions of both handling pads. Select each applicable stage exactly once and enter its clear dimensions under Space details. Stage width must equal the clear width between side walls. The sum of clear stage depths and all front/rear/partition wall thicknesses must equal the entered building depth. The goods lane must fit through every opening and the two pads must fit fully inside the plot. Required room relationships, area limits, supplied setbacks and stated coverage/FAR/FSI are checked. Unsupported or non-fitting input stops export without altering the saved brief or falling back to a zoning drawing.

Save automatically opens the result. Reopen via **Projects → Packhouse goods-flow CAD**. Editable DXF includes `PACKHOUSE_OPENINGS`, `PACKHOUSE_PADS` and a directional `PACKHOUSE_FLOW` layer. The arrows indicate the intended direction of goods, not a physical barrier, conveyor system, hygiene validation or a verified means of escape. Personnel access, truck turning, accessible routes, toilets, food safety/sanitation, equipment, commodity throughput and authority requirements require separate design. Washing, drainage, refrigerated rooms, separate raw storage, specialty process equipment and vehicle yards are not drawn in this template.
